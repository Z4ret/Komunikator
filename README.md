# Komunikator
Celem projektu jest stworzenie własnej aplikacji internetowej do komunikacji między użytkownikami, inspirowanej funkcjonalnością Discorda. Aplikacja będzie umożliwiała tworzenie kont, tworzenie i dołączanie do serwerów, korzystanie z kanałów tekstowych i głosowych oraz komunikację z innymi użytkownikami w czasie rzeczywistym.
